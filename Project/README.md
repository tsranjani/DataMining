## Set up project

Without venv (the packages are downloaded globally):

```bash
    pip install .
```

With venv (the packages are downloaded into local venv):

```bash
    python -m venv venv
    source venv/bin/activate
    pip install .
```

With uv:

```bash
    uv sync
```
